# รุ่น v5: Snapshot, เมนูด้านซ้าย และข้อมูลตั้งต้นจาก CV

## สิ่งที่เพิ่ม

- หน้าเว็บอ่านค่าที่ตรวจสอบล่าสุดจากเบราว์เซอร์ก่อน แล้วตรวจข้อมูลจาก Apps Script เบื้องหลัง
- เก็บค่าชุดใหม่เมื่อ API ตอบสำเร็จ จึงไม่ทำให้ Card ว่างในช่วงเครือข่ายสะดุด
- ประวัติการศึกษาเรียงจากปีสิ้นสุดหรือปีเริ่มต้นล่าสุดไปหาเก่าสุด
- เมนูสาธารณะเป็น Sidebar ด้านซ้ายบนจอคอมพิวเตอร์ และเป็น Drawer บนมือถือ
- ปุ่มเข้าสู่ระบบเปิด `admin.html` โดยตรง ไม่มีหน้าล็อกอินซ้ำในหน้าเว็บไซต์
- เพิ่มช่องจัดการวิดีโอภาคสนามใน Hero
- เพิ่มสคริปต์ `tools/cv_seed_draft.cjs` สำหรับนำเข้าข้อมูล CV แบบฉบับร่างและตรวจรายการซ้ำ
- เพิ่มภาพหลักฐานใบประกาศจาก CV ใน `assets/cv-evidence/`

## อัปเกรด Google Apps Script

1. สำรอง Apps Script รุ่นที่ใช้งานอยู่
2. แทนที่ไฟล์ `Code.gs` และ `SheetSetup.gs` ด้วยไฟล์ในโฟลเดอร์ `apps_script/`
3. รัน `migrateHeroFieldVideo()` หนึ่งครั้ง เพื่อเพิ่มคอลัมน์วิดีโอโดยไม่ล้างข้อมูลเดิม
4. Deploy > Manage deployments > Edit > New version > Deploy
5. ใช้ URL `/exec` เดิมได้ หากแก้ Deployment เดิม

## ตรวจข้อมูล CV ก่อนเผยแพร่

รายการที่นำเข้าเป็น `draft` ทั้งหมด ให้เข้าสู่ระบบหลังบ้าน ตรวจข้อความ ปี บทบาท และหลักฐาน แล้วเปลี่ยนสถานะเฉพาะรายการที่ยืนยันแล้วเป็น `published` หน้าเว็บจะตรวจพบและบันทึกเป็น Snapshot ล่าสุดโดยอัตโนมัติ

ข้อมูลตั้งต้นอ้างอิง CV ลงวันที่ 9 กรกฎาคม 2567 จึงไม่ควรถือว่าเป็นสถานะปัจจุบันหลังวันดังกล่าวจนกว่าจะตรวจทาน
