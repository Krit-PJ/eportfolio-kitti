# รุ่น v6: Professional Homepage

## การปรับปรุง

- ย้ายเมนูสาธารณะกลับเป็นแถบด้านบนตามลำดับที่อนุมัติ และเลื่อนแนวนอนได้บนจอแคบ
- ตัวปรับขนาดอักษรมี 3 ระดับ แสดง Active state, `aria-pressed` และบันทึกค่าที่เลือก
- Card ผลงานใช้ข้อมูล `published` จากฐานข้อมูลกลางผ่าน canonical data pipeline
- ประวัติการศึกษาใช้ข้อมูล `published` จาก Education โดยตรง เรียงปีใหม่ไปเก่า และแสดงสถานะแหล่งข้อมูล
- ป้องกัน API ที่ตอบรายการว่างผิดคาดเขียนทับ Last Verified Snapshot ที่มีข้อมูล
- เปลี่ยนเครือข่ายความเชี่ยวชาญเป็น Focus Explorer: เลือกหมวด เห็นจำนวนหลักฐาน และเปิดรายละเอียดผลงานได้
- แสดงวิดีโอภาคสนามเป็นกล่องวิดีโอพร้อม native controls ในหน้าแรก
- แสดง “เรื่องเล่า ย้อนรอย” เป็นบล็อกภาพหัวเรื่อง พร้อม fallback image ตามบริบทเมื่อรายการยังไม่ได้กำหนด Cover Image

## ข้อเท็จจริงของข้อมูลปัจจุบัน

ณ วันที่ตรวจ ระบบ API ตอบสนองปกติ แต่ชุดข้อมูลสาธารณะสถานะ `published` ยังไม่มีรายการ ดังนั้นหน้า Public จะแสดงศูนย์หรือข้อความ “ยังไม่มีรายการเผยแพร่” อย่างตรงไปตรงมา และจะไม่เปิดเผยรายการ `draft` อัตโนมัติ

เมื่อตรวจรายการในระบบหลังบ้านและเปลี่ยนเป็น `published` หน้าเว็บจะอ่านข้อมูลใหม่และบันทึกเป็น Last Verified Snapshot โดยอัตโนมัติ
