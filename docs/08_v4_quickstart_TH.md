# เริ่มใช้งานฉบับ V4

ชุดนี้เป็นโค้ดเว็บไซต์ครบชุด ส่วนฐานข้อมูลออนไลน์ต้องใช้ Apps Script ของเจ้าของเว็บไซต์ ไม่มีรหัสผ่านหรือ Token ฝังไว้ในเว็บไซต์

## เปิดตัวอย่าง

1. แตก ZIP เป็นโฟลเดอร์ใหม่
2. เปิด Terminal ในโฟลเดอร์ที่มี index.html
3. หากมี Python อยู่แล้ว ใช้ `python -m http.server 4173 --bind 127.0.0.1`
4. เปิด `http://127.0.0.1:4173/index.html`
5. เมื่อยังไม่ตั้ง API จะเห็นป้ายโหมดตัวอย่าง อย่าใช้จำนวนในตัวอย่างเป็นยอดยืนยันจาก Google Sheets

## อัปเกรดเว็บไซต์เดิม

1. สำรอง Google Sheets และไฟล์เว็บเดิม
2. เปิด Sheets > ส่วนขยาย > Apps Script แล้วแทนที่ Code.gs และ SheetSetup.gs ด้วยไฟล์ใน apps_script
3. ถ้าฐานข้อมูลยังไม่ผ่านรุ่นก่อน ให้รัน migrateRelationalPortfolioSchema, migrateDashboardStatisticLinks, migrateBlogKnowledgeHub และ migrateStoryEvidenceImages ตามลำดับ
4. รัน migratePortfolioV4 เพื่อเพิ่มรายละเอียดการทดลอง ทะเบียน Career และสถานะเผยแพร่ โดยไม่ล้างข้อมูลเดิม
5. ตรวจข้อมูล Publications และ Training: migration จะกำหนดรายการเดิมที่สถานะว่างเป็น published; เปลี่ยนรายการที่ไม่ต้องการเปิดเผยเป็น draft
6. ตรวจ Script Properties ให้มี API_TOKEN, ADMIN_USERNAME และ ADMIN_PASSWORD_HASH ตามคู่มือหลัก
7. Deploy > Manage deployments > Edit > New version > Deploy
8. ใส่ URL /exec ของ deployment ใน CONFIG.API_URL ของ index.html และ admin.html ให้ตรงกัน
9. อัปโหลดไฟล์ HTML รูปภาพ และ assets ไปยัง GitHub repository เดิม แล้วรอ Pages deploy สำเร็จ
10. เปิดเว็บจริงด้วย Ctrl+F5 และตรวจข้อมูล/การเข้าสู่ระบบตามคู่มือหลัก

setupAllSheets รุ่นล่าสุดรันซ้ำได้อย่างปลอดภัย: เติมเฉพาะโครงสร้างที่ขาด ไม่ล้างแถวข้อมูลเดิม

## จัดการเนื้อหา

- ระบบดิจิทัล: เพิ่มชื่อ คำอธิบาย Snapshot ลิงก์เข้าใช้งาน และสถานะ
- นวัตกรรม: เปิดหมวดโครงการ เลือกให้เป็นนวัตกรรม แล้วกรอกโจทย์ สมมติฐาน ต้นแบบ วิธีทดสอบ ผลที่พบ และขั้นต่อไป ข้อมูลนี้ผูกกับโครงการเดียวกัน
- งานวิจัย/ผลงานตีพิมพ์: กรอกข้อมูลอ้างอิงและ URL ที่เปิดได้จริง เลือก draft ขณะเตรียมข้อมูลและ published เมื่อตรวจแล้ว
- วิทยากร/R2R: ระบุบทบาทให้ชัดและแนบใบประกาศหรือ URL หลักฐาน
- เรื่องเล่า ย้อนรอย: บันทึกเรื่องก่อน แล้วใช้ปุ่มภาพหลักฐานของรายการนั้นเพื่อเปิดฟอร์มที่เลือกเรื่องไว้แล้ว เพิ่มภาพ หัวข้อ คำบรรยาย และลำดับ
- ประสบการณ์ทำงาน: เพิ่มใน Career พร้อมหน่วยงาน ช่วงเวลา และหลักฐาน ไม่ต้องกรอกยอดสรุปแยก
- ติดต่อ: จัดการในข้อมูลส่วนตัว (Profile)
- การแก้ไขใช้ปุ่มรูปดินสอ; การลบใช้ปุ่มถังขยะและยืนยัน หากรายการยังมีความสัมพันธ์ต้องย้าย/ลบความสัมพันธ์ก่อน

## ตรวจหลังเปิดใช้งาน

1. คลิกการ์ดสรุปแต่ละใบ ตรวจจำนวนกับรายการที่เปิดดู
2. สร้างรายการทดสอบแบบ draft และยืนยันว่าไม่ปรากฏหน้าสาธารณะ แล้วเปลี่ยนเป็น published เพื่อตรวจอีกครั้ง
3. ทดลองเปิดรายละเอียดความเชี่ยวชาญและหลักฐานที่เชื่อมโยง
4. เปิดวิดีโอ เลื่อนหน้า แล้วปิดกล่อง ตรวจว่าเสียงหยุด
5. ตรวจหน้าเว็บที่หน้าจอมือถือและขนาดกลางว่าข้อความไม่ทับรูปและกล่องลอยไม่กว้างเกินจอ
6. หาก API ขัดข้อง ต้องเห็นสถานะแจ้งปัญหา ไม่ควรเห็นข้อมูลตัวอย่างแทรกแทนข้อมูลจริง
